# One Word, One Username, One Reward

Our entry for the [make.fun bounty](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae): a tiny program that writes our own make.fun username — one word and nothing else — to `/output/entry.txt`.

Run it with Node 22.18 or later:

```sh
node main.ts
```

It writes exactly `oreo` (4 bytes, no trailing newline) to `/output/entry.txt`.
